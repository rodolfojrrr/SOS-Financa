# Atualizar para SOS Finança V4.0.0

1. Faça backup no app atual.
2. Feche o SOS Finança.
3. Extraia `SOS_Financa_Atualizacao_V4.0.0_GITHUB.zip`.
4. Execute `ATUALIZAR_SOS_FINANCA_V4.bat`.
5. Aguarde Build Windows e Build Android no GitHub.
6. Instale os novos builds somente quando os workflows estiverem verdes.

O identificador `com.sosfinanca.app` e o banco `sos_financa.db` foram preservados.
