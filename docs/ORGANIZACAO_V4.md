# Organização da interface — V4

A regra da V4 é **pasta → conteúdo → ação → modo Editar**.

## Cartões
Cada cartão é uma pasta personalizável com limite, utilizado, disponível, fatura, compras, pagar fatura e modo Editar.

## Gerenciar
Gerenciar fica direto no menu desktop/mobile e usa pastas: Movimentações, Receitas Fixas, Contas Fixas, Cartões, Dívidas, Contas e Categorias, Planejamento e Lixeira.

## Lixeira
Excluir pede confirmação, envia para Lixeira e permite restaurar. Exclusão permanente pede nova confirmação e cria tombstone para a sincronização.

## Alertas
Alertas do dashboard levam diretamente para o item que precisa de ação.
